Colour comes from the sky, not the chrome

The palette has two halves. One is borrowed light — the weather and the hour, washed over the whole room and never fixed. The other is a small, disciplined set of fixed inks and signals that never shift, so text and state stay legible whatever the light is doing. This is every token, with the value and the reason.

Borrowed light · the atmosphere set

Seven states of weather, as a wash — not a fill

Each atmo-* token is a single translucent tint laid over whatever photo is up (values are the Mode-0 overlay; the awake substrate runs a touch lower). It settles over 60 s and never loops. Shown here over one neutral frame so you can read the light each one casts.

Borrowed light · the living accent

One accent that walks through the day

A single --accent, set by the hour, quietly tints the clock and the view titles together so the whole face shifts as the day turns — cool at first light, warm at dusk, cool again at night.

Fixed · signals

Status means one thing everywhere — and one warm hue, reserved

Semantic colour is shared across cameras, system status and automation; it is not decoration and never doubles as the accent. Tinted badges use color-mix(in oklch, …), not hard-coded rgba. The single warm hue is for sun and lightning glyphs only.

The colour rules

How the two halves stay apart

  • 01Colour is borrowed from the weather and the hour (atmo-*, --accent), never painted onto chrome. If a panel wants colour, it takes it from the light.
  • 02Ink never shifts with the accent. Legibility is fixed; mood is not. Use --ink / -dim / -faint, never a raw white.
  • 03Status is meaning, not decoration. ok/warn/error/info are shared and never used as an accent; tinted badges via color-mix.
  • 04One warm hue, reserved. --warm is for sun/lightning glyphs and the arrival name — nowhere else.
  • 05Glass is all-or-nothing. The five properties travel together; never a one-off backdrop-filter in a component.
